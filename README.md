# Early Prediction of Chronic Kidney Disease

A machine learning-based desktop application for the early prediction of Chronic Kidney Disease (CKD). The application provides a simple Tkinter graphical interface for loading a dataset, preprocessing the data, training multiple machine learning algorithms, comparing their accuracy, and performing predictions on CSV data.

## Features

* Upload CKD datasets in CSV format
* Handle missing values using the dataset mode
* Encode categorical features using Label Encoding
* Split the dataset into training and testing data
* Train and evaluate multiple machine learning algorithms:

  * K-Nearest Neighbors (KNN)
  * Naive Bayes
  * Logistic Regression
* Display model accuracy
* Generate an accuracy comparison bar graph
* Perform predictions using a trained Logistic Regression model
* Simple desktop GUI built with Tkinter

## Technologies Used

* Python
* Tkinter
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Machine Learning Algorithms

### K-Nearest Neighbors (KNN)

KNN classifies data points based on the nearest training examples.

### Naive Bayes

Gaussian Naive Bayes is used for classification based on probabilistic relationships between the features.

### Logistic Regression

Logistic Regression is used as a classification model for predicting the target class.

## Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd Early-Prediction-of-Chronic-Kidney-Disease
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

On Windows:

```powershell
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install pandas scikit-learn matplotlib
```

## Run the Application

Start the application with:

```bash
python app.py
```

The Tkinter desktop application will open.

## How to Use

1. Click **Upload Dataset**.
2. Select a CKD CSV dataset.
3. Click **Split Dataset**.
4. Run **KNN**, **Naive Bayes**, or **Logistic Regression**.
5. View the accuracy results.
6. Click **Plot Results** to compare model accuracy.
7. Use **Prediction** to load CSV data and generate predictions using the trained Logistic Regression model.

## Dataset

The project includes sample CKD datasets inside the `Dataset` folder.

The dataset contains medical-related attributes used for classification of Chronic Kidney Disease.
